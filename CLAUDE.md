Keep code concise with minimal but useful documentation.

Use uv for dependency management and `uv run` to run scripts.

Put any session notes, longer text analyses, purely temporary code, or any other session artifacts you want to keep but that aren't part of the main flows in `claude_notes/`.

Do not edit anything outside of this directory. Put outputs into an `outputs/` directory.

This is a work-in-progress radar sounder simulator designed primarily for instrument engineering work focused on Earth's ice sheets.

* `reference_papers/` contains PDFs of relevant literature to radar sounding simulation
* `docs/` is user-facing documentation about the simulator tools and its methadology
